# Personal Task Board (AI-as-Copilot Lab)

This repository contains the results and documentation for the **"Module 02 Lab: Hands-On PRD Creation with AI (AI-as-Copilot Version)"**.

The primary goal of this project is not to write code directly, but rather to learn how to automate and standardize processes such as **project planning, template creation, and requirements analysis (PRD, Epic, Story)** by using Artificial Intelligence (AI) as a Copilot.

## 🗂️ Project Structure & Deliverables

The application does not have a coded interface yet. The following structures were completely analyzed and generated through AI prompts:

- **`agents.md`**: Defines the rules and configurations (Tech Stack, Naming Conventions) that AI assistants working on the project must follow.
- **`.github/prompts/`**: A library of custom, reusable prompts created by AI for GitHub Copilot.
- **`specs/templates/`**: Markdown templates generated by AI to standardize the creation of PRDs (Product Requirements Documents), Epics, and User Stories.
- **`specs/prds/`**: The main document describing all the features, goals, and user scenarios of the "Personal Task Board" application.
- **`specs/epics/`**: The application broken down into 3 main Epics based on the PRD (Core UI, Task Management, Persistence/Drag & Drop).
- **`specs/stories/`**: Detailed User Stories and Acceptance Criteria based on the "INVEST" principles, specifically broken down from one of the Epics (Task Management).

## 🚀 Planned Tech Stack

If the project proceeds to the coding phase, the following technologies are planned to be used:
- **Framework:** React 18 (with Vite)
- **Language:** TypeScript (Strict Mode)
- **Styling:** Vanilla CSS (Modern, Dark Mode, and Glassmorphism focus)
- **Data Storage:** Browser `localStorage` (100% offline functionality without a backend or database)
